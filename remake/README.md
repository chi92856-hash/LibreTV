# LibreTV 新版

新版以 M HUB 的黑色工作台和胶囊控件为设计参考。发现页、搜索、片单、历史和播放工作台由本目录实现。

Windows 桌面预览可在仓库根目录运行 `node remake/build-desktop.cjs`。脚本用本机已安装的 Electron 运行文件打包到 `.local-runtime/libretv-remake`。打开生成的 `LibreTV Remake.exe` 即可使用。另一种运行方式是在本目录安装 Electron 后执行 `npm run desktop`。

网页预览在仓库根目录运行 `node remake/server.cjs`，然后打开 [本机预览](http://127.0.0.1:8900/)。

首页精选可以自动轮播，大海报和小海报都有鼠标跟随动效。点海报或「查找片源」会搜索片名，选中结果后可以切换线路、选集或加入片单。

精选片库的「换一批」会按当前分类或标签加载豆瓣推荐的下一页，跳过本次浏览中已经展示的片名。推荐用完或请求失败时，界面会给出提示并保留当前海报。

「设置 → 自定义 API」可添加、编辑或移除苹果 CMS JSON 采集接口。「全部片源」会一起查询内置和自定义片源，也可在设置中单独选择一个。精选片库右侧的「管理标签」可添加、重命名和移除标签，自定义标签按名称匹配精选影片的片名、类型或年份。

收藏、观看进度、片源和标签存储在当前运行环境的本机数据中。

电影剧照和海报用于精选展示，来自 TMDB 图片服务。HLS 播放使用 hls.js。
