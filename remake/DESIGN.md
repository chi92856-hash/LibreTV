# LibreTV 新版：浅色薄雾玻璃

依据用户于 2026-11-22 确认的效果图，以及 RVC 前端设计与动态交互复用说明实装。

## 视觉与布局

- 基础色为 `#F8FBFC`、`#EEF4F8`，主文字 `#253747`，辅助文字 `#566D80`。
- 冰蓝胶囊承担选中状态；白色上沿高光和柔和阴影表达局部玻璃层次。
- 桌面顶部保留品牌及窗口操作，左侧为发现、片单、观看记录，设置固定在左下。
- 主区依次为搜索、片源入口、精选推荐、分类与标签、海报片库、真实继续观看记录。
- 海报和影片信息复用现有内容，不用概念图中的生成海报替换真实素材。
- 没有历史记录时隐藏继续观看；旧记录缺少时长时只展示已观看时间，不猜测进度比例。
- 播放页面、搜索、设置、标签管理使用同一浅色系统。视频画面本身保持黑底。
- 600px 以下导航移至底部；片库按可用宽度排列，桌面宿主仍保留原最小窗口尺寸。

## 动态交互

- 导航与分类使用共享装饰胶囊，跟随焦点、悬停和真实选择；悬停不改变业务状态。
- 胶囊采用临界阻尼弹簧，快速切换从当前位置继续，稳定后停止请求动画帧。
- 按钮内部内容最多偏移横向 4px、纵向 3px；按钮本身和点击范围保持稳定。
- 搜索、设置和标签面板由入口位置展开，关闭后收回并恢复焦点；支持 Esc 和面板外点击。
- 详情使用原有 dialog 与真实表单节点，避免克隆造成值或事件丢失。
- 遵循系统减少动态效果设置；触屏不启用磁吸。
- 材质由 CSS 背景、模糊、高光和阴影构成，不捕获桌面，不宣称真实折射。

## 文件

- `web/style.css`：主题、布局、材质、响应式与状态。
- `web/index.html`：导航、搜索入口和继续观看容器。
- `web/app.js`：原业务逻辑、历史展示、胶囊和面板交互。

本机桌面版本由仓库根目录的 `node remake/build-desktop.cjs` 更新，保持原本机来源和用户数据目录。
